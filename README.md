# SwitchU Themes

Theme catalogue for [ncarvalho99/SwitchU](https://github.com/ncarvalho99/SwitchU).
The menu reads `index.json` from this branch and downloads a theme only when
one is installed, so nothing here is part of the build.

A theme is a background image, a set of colours, and the parameters for the
drifting shapes the menu draws over it. There is no video playback in SwitchU;
these were built from looping clips by taking a representative frame and
matching the shape layer to what the clip does.

Layout: `themes/<id>/theme.json`, with assets under `themes/<id>/media/`.
